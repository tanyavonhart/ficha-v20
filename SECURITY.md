# Segurança e privacidade

As fichas ficam no armazenamento do próprio navegador. Só saem do aparelho se você ligar:

- **Webhook do Discord:** as rolagens vão para o canal configurado.
- **Sincronização:** as fichas sobem para o espaço identificado pelo seu código, protegido por PIN (guardado apenas como hash). Quem tiver o código e o PIN consegue ler as fichas.

Encontrou uma falha? Abra uma issue **sem incluir seu código de sincronização, PIN ou webhook**, descrevendo o problema. Se for algo sensível, marque na descrição para tratarmos em particular.
