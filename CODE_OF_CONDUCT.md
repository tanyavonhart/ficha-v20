# Código de conduta

Este é um projeto de RPG feito por fãs. A regra é simples: **trate as pessoas como gostaria de ser tratado numa mesa**.

- Sem ataques pessoais, assédio ou preconceito de qualquer tipo.
- Críticas são bem-vindas quando são sobre o código ou a regra, não sobre a pessoa.
- Discordar faz parte; quem mantém o projeto decide o rumo.

Comportamento fora disso pode levar ao bloqueio nas discussões do repositório.
